# PLP Python Week 4

This assignment practices Python functions, parameters, return values, and default parameters.

- `welcome.py` - Contains a `welcome()` function that creates and prints personalized PLP welcome messages.
- `toolbox.py` - Contains three functions: `double()`, `is_pass()`, and `greet()`.

The `greet()` function was the hardest to write because it uses a default parameter for the greeting. I had to understand how the function uses `"Hello"` when no other greeting is provided.
